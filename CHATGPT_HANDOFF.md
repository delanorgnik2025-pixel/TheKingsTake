NATIONAL ARCHIVES CATALOG API — INTEGRATION PLAN  ### 5.1 What It Is  The National Archives and Records Administration (NARA) provides a **free, public  API** to search 500+ million federal records. This includes:  - Dawes Rolls (Five Civilized Tribes: Cherokee, Choctaw, Chickasaw, Creek, Seminole)  - Guion Miller Rolls (Eastern Cherokee)  - Baker Rolls (Eastern Cherokee)  - Census records (1790–1940)  - Treaty documents  - Land cession records  - Military service records  API Docs: https://catalog.archives.gov/api/v1/api-docs/  Base URL: `https://catalog.archives.gov/api/v1`  No API key required. Rate limited but generous.  ### 5.2 What We Can Build  **Phase 1 — Dawes Rolls Search (MVP, 2 weeks)**  - Search by surname  - Search by tribe  - Search by roll number  - Results: name, age, sex, blood degree, census card number, enrollment number  - Display in a clean table with download option  **Phase 2 — Advanced Search (1 month)**  - Multi-field search: surname + state + year range  - Filter by record type (Dawes, Guion Miller, Baker, Census)  - Save searches to user profile  **Phase 3 — Cross-Reference Tool (2 months)**  - Input: family surname + state(s) of origin  - Query: NARA catalog + census + treaty records  - Output: auto-generated research brief showing all records found  - This becomes the ENGINE behind the Ancestral Land & History Report  ### 5.3 Technical Implementation  ```typescript  // api/nara-router.ts — tRPC router for NARA catalog queries  import { z } from 'zod';  const NARA_BASE = 'https://catalog.archives.gov/api/v1'  export const naraRouter = router({    search: publicProcedure    .input(z.object({      q: z.string().min(1), // search query      rows: z.number().default(20),      type: z.enum(['Dawes','Guion Miller','Baker','Census','Treaty','All']).default('All')    }))    .query(async ({ input }) => {      const url = `${NARA_BASE}/?q=${encodeURIComponent(input.q)}&rows=${input.rows}`      const res = await fetch(url)      const data = await res.json()      return data.opaResponse.results.result    }),  })  ```  ### 5.4 Why This Is a Competitive Moat  - **native-land.ca** = free, academic, no primary-source search  - **Ancestry.com** = $300/yr, not focused on Indigenous heritage  - **FamilySearch** = free but LDS-owned, not culturally aligned  - **TheKingsTake** = free map + premium deep research + direct NARA search = **unique positioning**  Nobody serves the **Black American + Indigenous heritage** intersection with primary-source tools.
